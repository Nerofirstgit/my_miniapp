# 首页五项反馈修复验证

日期：2026-10-18（Asia/Shanghai）。本轮是反馈修复，尚未获用户真机验收。

## 实现与边界

- 首屏和分区标题都有连续循环；外层负责一次入场/按压，内层负责8秒周期的错峰文字波动。节奏参考网站3秒扫过、5秒停顿；原生字形缩放/倾斜与彩色边缘是近似，未复刻 Three.js 逐像素 shader。
- 联系按钮使用原站电话、微信、邮箱三枚线框图标，按用户确认去掉中英切换和动效开关。电话/微信仍使用小程序联系弹层，邮箱仍复制。
- 内容透明度按滚动进度双向改变，覆盖关于、作品、经历、技能与联系。关于按段落而非逐字显现；页底终点截断到最大滚动距离。
- 移除菜单三横线，整栏点击或下拉40px展开；松手保留菜单，点击条目才导航。
- 星点错峰呼吸、星场位移、星云明暗变化及5层白雾漂移。白雾参数在每次加载时随机，轨迹本身循环；非连续随机粒子模拟。
- 菜单/联系弹层打开及页面隐藏时暂停渲染层循环。系统减少动态效果媒体查询保留；本轮未在真实系统偏好设置下验证。
